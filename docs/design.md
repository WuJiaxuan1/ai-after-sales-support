# 系统设计

## 职责与控制权

`src/server/engine/service.py` 中的 `AfterSalesService` 组织流程、安全判断、检索与人工交接。模型提出结构化判断，业务规则负责校验和执行状态变更。

| 模块 | 职责 |
| --- | --- |
| `engine/workflow.py` | 既有流程导航、连续候选路径校验和用户确认 |
| `engine/safety.py` | 高优先级安全规则与否定语境处理 |
| `ai/adapter.py` | 路径映射、安全语义分类、检索回答、人工交接判断及降级 |
| `engine/rag.py` | Markdown 知识检索；普通售后知识与安全知识分离加载 |
| `engine/handoff.py` | 创建人工交接包和维护接管状态 |
| `engine/priority.py` | P0–P3 优先级；基于已核验信息计算经济暴露 |
| `engine/case_manager.py` | Case、消息和审计状态 |
| `client/src/views/AgentView.vue` | 队列、交接信息、接单、回复和解决操作 |

## 关键判断

- 自由文本可以提出跨节点的可靠候选路径，但只能使用既有合法流程，并需要用户确认。
- 普通知识咨询允许进入 RAG，无须先完成所有业务分类。
- 安全风险成立时创建真实人工交接并设为 P0，不能仅让 AI 回复“已经转人工”。
- 用户自报金额不直接成为已核验经济暴露，也不交由模型自由决定优先级。
- 客服接单、回复和解决受状态约束，前端显示需要与后端业务状态一致。

## 公开版本配置

模型密钥从 `MIMO_API_KEY` 环境变量读取。`MIMO_BASE_URL` 和 `MIMO_MODEL` 可以覆盖原默认值。未设置密钥时，现有适配器走规则与降级路径；这只用于规则演示，不代表完整模型功能已验证。
